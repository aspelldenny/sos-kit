## Self-approve-safety (O1.1 resolution)

Two layers now gate the exemption:
1. **Actor-check (NEW):** only fires when neither subagent marker is present — mirrors `orchestrator-guard.sh:596`'s `[ -f ".sos-state/worker-active" ] && continue` precedent. A worker-authored patch touching only `ticket-state.env` now falls through to the ordinary version-match BLOCK.
2. **All-path check (P078d2a #6, unchanged):** a patch bundling `ticket-state.env` with any second path still BLOCKs regardless of actor.

Test `approval_gate_blocks_state_file_alone_write_when_worker_active_self_approve` is the core security oracle proving self-approve is blocked. Negative-test (see below) confirms the check actually bites.

## Coupling note (mandatory)

Safety of the extended exemption rests on BOTH layers together, not either alone:
- Actor-check alone would still be bypassable if #6 were absent (a worker could bundle a forged approval + code change in one patch, assuming actor-check false-negatived some other way) — not the case here since #6 is untouched and independently tested (`approval_gate_blocks_multipath_bundle_state_file_plus_code_even_main_thread`).
- All-path check alone (pre-P078e state) was NOT enough — it permitted create-when-missing self-approve once (accepted risk, d2a) and would have permitted every future self-approve-via-lone-write had this phiếu's fix not added the actor-check.

## Codex caveat — honest, not SOUND on Codex

The actor-check depends on `.sos-state/worker-active`/`architect-active`, which per P078d2b (gap #6, `openai/codex#21753`) are **not reliably set inside custom-role Codex subagents**. On Claude, subagent hooks fire reliably — the check is correct and complete. On Codex, a worker subagent's `apply_patch` may not route through this in-session hook at all, so the actor-check is defense-in-depth only. The real backstop for approval-record integrity on Codex remains **human-review-at-the-git-commit-boundary** — documented in both `adapters/codex/CAPABILITY.md` §4 and `SECURITY.md`. Not claiming full self-approve protection on Codex.
