## Assumptions vs Reality

### CORRECT
- `.sos-state/` blanket-ignore in `.gitignore` confirmed on line 13.
- The directory-pattern `.sos-state/` (trailing slash) ignores the ENTIRE directory, so negation `!.sos-state/sos-kit-self` does NOT work when using the directory form. **Fixed:** changed to `.sos-state/*` (glob matching files within dir) + `!.sos-state/sos-kit-self`. Verified: `git check-ignore .sos-state/sos-kit-self` exits 1 (not ignored); `git add --dry-run .sos-state/sos-kit-self` succeeds.
- `orchestrator-guard.sh` uses `.md` exemption via `case` statement, mirrored correctly.
- Extension union `\.(rs|ts|tsx|js|jsx|py|go|swift|pbxproj)$` covers all type mappings.

### WRONG (Tầng 2 self-adapt)
- **`.gitignore` pattern form:** Initial write used `.sos-state/` (directory pattern) + negation → negation silently ineffective (git gitignore §3: cannot un-ignore a file in an ignored dir without un-ignoring the dir). Fixed to `.sos-state/*` before commit. Self-adapted (Tầng 2 — pure shell/config implementation detail, no API/schema/signature change).
