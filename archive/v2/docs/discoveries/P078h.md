## Gap #3 note (implementation)

Replaced the fall-through with an unconditional early-BLOCK: if `ACTOR_IS_MAIN_THREAD == 0`
(either marker present) **and** any path in the (now-normalized) `NON_TICKET_PATHS` set equals
`.sos-state/ticket-state.env`, the guard exits 2 immediately with a
`"control-plane write by marked actor: blocked"` message — before the pre-existing
create/update exemption `if` and before the version-match fail-CLOSED check further down. This
means version-match is now reached **only** on the main-thread path (both markers absent).
Main-thread behavior (P078e deadlock exemption) is completely untouched — the early-BLOCK's `if`
guard is scoped to `ACTOR_IS_MAIN_THREAD -eq 0` only.

## Gap #4 note (implementation)

Inside the same `NON_TICKET_PATHS`-building loop, added: strip a literal `"$REPO_ROOT/"` prefix
from any path that starts with it; if the resulting normalized form still contains `..`
(shouldn't happen given a plain prefix strip, but kept as a belt-and-braces conservative check),
fall back to the raw path unmodified. Any path that is absolute but **not** under `$REPO_ROOT`
is left completely as-is — it will never equal the exact `.sos-state/ticket-state.env` string, so
it can never win the state-file-allow exemption; it always falls through to the normal
fail-CLOSED checks. This is a plain string-prefix strip, not a `realpath`/symlink resolution —
deliberately conservative per the phiếu's Constraint #3.
