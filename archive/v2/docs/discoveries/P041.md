## Edge cases / limitations found

- `package_lock_v3.py` handles both lockfileVersion 2 and 3 (npm flat packages layout). lockfileVersion 1 raises ValueError.
- PyYAML system package install on macOS with Python 3.14 required `--break-system-packages`. Trinh sát Bước 0 should handle this gracefully — the `|| pip3 install pyyaml` fallback may need the flag in modern macOS environments. Noted as potential follow-on issue.
