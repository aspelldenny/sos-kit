## Quyết định

Chủ nhà chọn ownership A: giữ Rust CLI trong `sos-kit`, nâng repo thành monorepo module hóa, phát hành một version và expose một binary/product entrypoint `sos`. Portability đến từ crate/adapter boundary, không từ việc bắt buộc tách repo.

## Findings

- Claude coupling nằm ngoài `.claude/**`: `CLAUDE.md`, agent frontmatter, canonical docs, skills, Bash CLI và lifecycle scripts đều có runtime vocabulary hoặc serialization.
- `.claude/agents/**` và `.claude/skills/**` hiện là tracked symlink registration. Đây là generated-adapter shape tốt, nhưng source/target ownership chưa được manifest hóa.
- Universal Git gates đã gần portable; target hook chỉ cần dispatch về `sos hooks run ...` thay vì chứa nhiều policy shell.
- `install.sh` đã chứng minh one-command demand nhưng đang giữ hard-coded tool inventory và cài nhiều binary trước khi có một product manager. Target: thin bootstrap tải `sos`; `sos install` quản tool manifest, adapter, hooks và doctor.
- Một lệnh cài không bắt buộc nhập source của mọi sister tool. Khóa version/checksum và dispatch từ `sos` cho phép migration dần, tránh big-bang rewrite.
- `bootstrap/sos-rs/README.md` và `CLAUDE.md` đang phản ánh ownership cũ (extract Rust repo; repo không chứa runtime source). P077 sở hữu contract update khi tạo workspace chính thức.
