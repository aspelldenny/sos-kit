- `docs_dir = ""` (default empty = repo root)
- `changelog = "CHANGELOG.md"`
- `changelog_max_age_days = 1`
- `changelog_staged = true`

Key discovery: `changelog` path is **relative to `docs_dir`**, not to repo root. With `docs_dir = "docs"`, `changelog = "CHANGELOG.md"` resolves to `docs/CHANGELOG.md`. Since sos-kit's changelog is at repo root, the dogfood config uses `changelog = "../CHANGELOG.md"` to step up one level. This was a Tầng-2 in-flight fix — no escalation needed.

## Hook edit approach

Anchor #8 found a **single** docs-gate invocation block (lines 73–84). Used the single-wrap pattern — no flag variable needed.

Guard structure (inserted before the `command -v` check):
```
if [ ! -f .docs-gate.toml ]; then
    yellow warning + WARN_COUNT++ → skip entire docs-gate block
elif command -v docs-gate ...; then
    ... existing invocation ...
else
    binary-not-found warning (existing)
fi
```

This is the cleanest pattern: missing config → skip (warn), binary present + config present → run, config present + binary absent → skip (existing behavior). No early exit — other checks (type-check, BACKLOG, Discovery) continue independently.
