## Discovery Report

P075 extracted a compact neutral contract instead of copying nearly 4,000 lines of mixed operational documentation.

### Assumptions trong phiếu — ĐÚNG:

- P074 boundary forbids host event/tool/model/environment/path vocabulary in portable core.
- Existing role handbooks mix semantic responsibilities with execution metadata and concrete tool names.
- Existing doctrine contains the complete draft, challenge, approval, execute, discovery and delivery lifecycle.
- Tickets, recipes, stack configs, project templates and universal Git gates already provide a portable asset base.

### Assumptions trong phiếu — SAI:

- V1 asked `core/ASSETS.md` to catalog exact current adapter paths while also requiring zero runtime tokens. CHALLENGE caught the contradiction before execution. V2 keeps exact path evidence in P074 inventory and makes core own only semantic classes plus portable paths.

### Edge cases phát hiện thêm:

- Runtime neutrality needs a capability vocabulary, not removal of all operational detail. Stable names such as `read_files`, `run_commands`, `ask_human` and `delegate_work` let adapters map different host APIs without changing role semantics.
- A portable contract cannot immediately become the executable oracle without risking behavior drift. P075 therefore makes extracted semantics canonical while preserving current operational files as the parity oracle until P076.
- User feedback re-confirmed the existing one-ticket/one-merge rule: completion now explicitly includes remote-state verification before the next ticket executes.
