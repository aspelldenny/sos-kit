## Worker CHALLENGE (Turn 1) → Architect ACCEPT V2 — 2 objections resolved

1. **O1.1 (self-closed, non-blocking):** Task 1 prose said "emit before `[agents]`" but `[mcp_servers.doctor]` is the FIRST table header in the file — root keys placed merely before `[agents]` (between the two headers) would still nest under `[mcp_servers.doctor]`. Fixed by emitting `sandbox_mode`/`approval_policy` before the FIRST header in the file (verified: they now render before `[mcp_servers.doctor]`).
2. **O1.2 (Architect V2 revision):** Task 0 anchor #5 / Task 4.2 / Nghiệm thu originally mandated parsing `.codex/rules/*.rules` with the `toml` crate — empirically confirmed impossible (`.rules` is Starlark function-call syntax, `toml::from_str` errors on `prefix_rule(...)` deterministically, verified in a scratch cargo test before V2). V2 replaced this with a **structural-string oracle** (`content.contains("pattern = [\"git\", \"push\", \"--force\"]")` + `!content.contains("pattern = \"")`) — weaker than a real parser but sufficient to catch the exact bug class, avoids a Tầng-1 new-dependency (Starlark parser crate) for a test-only assertion.

## Oracle-honesty note (structural-oracle-gap, b2/b3 lesson — MANDATORY)

- **config.toml / hooks.json** — real-parser (`toml`/`serde_json`) + schema-shape assert. Sound for structural correctness; still an **approximation** of Codex's actual `serde` deserializer (e.g. does not model every field Codex's `AgentRoleToml`/hooks struct accepts/rejects beyond the 3 confirmed bugs).
- **rules** — structural-STRING assert only (documented limit: `.rules` is Starlark, not TOML/JSON; no real parser available without adding a Tầng-1 dependency for a test-only need). Weaker than the other two.
- **In all 3 cases: structural-valid + shape-assert PASS here does NOT prove Codex 0.145.0 accepts the render.** This is exactly the P079 lesson — the pre-P078d1 oracle (generic valid-TOML/valid-JSON) PASSED while all 3 startup-blockers were live against real Codex. Only a live Codex 0.145.0 run (Nghiệm thu "Manual Testing" row) is ground-truth. This oracle catches the 3 *confirmed* bug classes; it does not guarantee no 4th unknown schema mismatch exists.
