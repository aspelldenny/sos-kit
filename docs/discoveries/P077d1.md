## Live gotcha found+fixed mid-EXECUTE (Tầng 2 self-decide, no escalation)

`adapter.rs`'s original module doc-comment cited the dep-direction guard's own forbidden token list **verbatim in prose** — `` `sos_adapter`/`sos_install` `` — to explain why the module must stay host-neutral. The guard's implementation is a plain substring scan (`content.contains(token)`), so writing those exact strings inside a comment tripped the guard as a false-positive violation (`cargo test` failed: "forbidden token `sos_adapter`" / "`sos_install`" found in `adapter.rs`). Fixed by rewording the comment to describe the tokens without spelling them literally ("a forbidden sos crate-name import — see `tests/dep_direction.rs`'s token list"). Re-ran `cargo test --workspace` — guard green. No design/scope change; pure prose fix. Worth noting for future contributors: the guard is a dumb string scanner, doc comments about it are also subject to it.
