## Implementation notes

### Task 3 — `$SHA_CMD` probe
Inserted after platform echo (L70), before "2. Prebuilt binaries" section. POSIX sh `if/elif/else` — no bashisms. `$SHA_CMD` is a plain string (not array) so `shasum -a 256` word-splits at the call site — correct for `#!/bin/sh`.

Probe order: `sha256sum` first (Linux-native; macOS `/sbin/sha256sum` Darwin 1.0 also fires here), `shasum -a 256` fallback (macOS standard, Git Bash). Comment correctly documents that macOS may use either — it will pick `sha256sum` if `/sbin/sha256sum` is on PATH (which it is on this machine and likely all modern macOS).

### Task 4 — verify block in `fetch_bin()`
Inserted between `curl` success branch and `mv "${dest}.tmp" "$dest"`. Uses `$2` (the `required|optional` flag already passed by callers at L88/L95) — POSIX sh positional parameter semantics confirmed correct (self-closed oracle in CHALLENGE Turn 1).

Fetch strategy: curl `${url}.sha256` to `${dest}.sha256.tmp` with same HTTPS/proto flags. On success: `cut -d' ' -f1` to extract hash (first-field, handles both `sha256sum` "hash  file" and `shasum -a 256` "hash  file" output formats). Recompute on `.tmp` (NOT on the final path — file still `.tmp` during verify). String-compare. On mismatch: rm `.tmp`, `return 1`. On curl fail (missing `.sha256`): rm partial, branch on `$2` (required→abort, optional→warn). `return 1` propagates to existing caller loops (L129 abort for required, L136 warn for optional) — no new exit paths added.

## Edge cases / limitations

1. **`shasum` branch not exercised on this mac** (all 3 test cases used `sha256sum`). To test the `shasum` branch: `PATH=$(echo $PATH | tr ':' '\n' | grep -v /sbin | tr '\n' ':') sh install.sh` (mask `/sbin` from PATH). Not done in this run — Linux dogfood will exercise `sha256sum` natively, and the `shasum` branch needs a mac without `/sbin/sha256sum` or explicit PATH masking.

2. **`set -eu` interaction**: `curl -fSL ... 2>/dev/null` — the `2>/dev/null` suppresses the "no .sha256" error output from curl (we want our own message). The curl exit code still propagates to the `if` — this is correct. `set -eu` does not kill the script mid-`if` when the condition is false.

3. **`.sha256.tmp` cleanup on `set -eu` abort**: if `cut` or `$SHA_CMD` fails (not expected but `set -eu` means any non-zero exits the script), the `.sha256.tmp` file might linger. Low-risk for installer use; a trap-based cleanup would be production-grade but was not added (out of scope per constraint: POSIX sh, no bashisms, minimal additions).
