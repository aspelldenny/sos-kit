## Key findings

### P071 → github-script@v7 interaction (the trap P009 oracle missed)

P009 (the original Node20 oracle) predates P071. P071 added `actions/github-script@v7` to the publish job across 5 repos (doctor, claude-hooks, docs-gate, ship, advisory-inbox) and inv-gate already had it. `github-script@v7` is a Node20 action — it was invisible to P009 because P071 didn't exist yet. This is the core reason P072 was needed: P009 fixed checkout+release, but a subsequent phiếu (P071) re-introduced a Node20 action. Lesson: after any phiếu that adds a new GHA action, check the `runs.using:` field before assuming it's node24.

### The 4 optional repos (guard, vps, doc-rotate, advisory-cron) had old-style release.yml

These repos did NOT get P071's draft/publish restructure. Their release.yml used a scalar `files:` (single file name), no draft/publish split, no sha256, no github-script. The phiếu correctly identified this and authorized applying the full doctor template in the same touch. Result: P071+P072 combined for these 4 — they now have sha256 checksums AND node24 actions in a single commit.

### doc-rotate CHANGELOG discovery

doc-rotate has TWO CHANGELOG files: `CHANGELOG.md` at repo root AND `docs/CHANGELOG.md`. The `.docs-gate.toml` monitors `docs/CHANGELOG.md` (relative to `docs_dir = "docs"`). First commit attempt failed because only the root CHANGELOG was staged. Fix: also stage `docs/CHANGELOG.md`. Both files now updated.

### advisory-cron CHANGELOG discovery

advisory-cron also has `docs/CHANGELOG.md` monitored by docs-gate (`changelog_staged = true`). Not visible from repo root. Commit blocked first attempt; adding `docs/CHANGELOG.md` to staging resolved it.

### No immutable-release race triggered on the 4 optionals

The phiếu warned that guard/vps/doc-rotate/advisory-cron might hit the "immutable release" race (concurrent matrix jobs trying to create the same release). After applying the full draft/publish template (matrix jobs create `draft: true` → single `publish` job flips to `false`), the rc runs completed with no race condition. The template works.

### Zero Node20 annotations on any of the 10 rc runs

Every log scan showed only `serde_yaml v0.9.34+deprecated` (a Rust crate deprecation notice, not a GitHub Actions Node20 runtime warning). Zero GHA Node20 deprecation annotations on all 10 runs. Completeness oracle passed fleet-wide.
