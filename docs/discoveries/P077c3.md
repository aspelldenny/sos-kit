## Normalization bugs found + fixed (load-bearing, see `tests/README.md`)

1. **Order-of-operations, full ISO-8601 timestamp:** `strip_timestamp` (full ISO-8601 → `<TIMESTAMP>`) must run BEFORE `normalize()`'s bare-date rule, in both `capture.sh` and `parity.rs`. Caught by the mandatory 2-run determinism check (first attempt: `.sos-stack.toml` hash differed between 2 capture runs — traced to the literal seconds-of-day surviving normalization).
2. **Locale-dependent `sort`:** a bare `sort` on this macOS host (non-C locale) ordered `templates/claude-settings.local.json` before `templates/INVARIANTS-template.md` (case-insensitive-ish collation), which mismatched Rust's plain byte-order `Vec<String>::sort()`. Fixed by pinning `LC_ALL=C sort` in `capture.sh`'s `freeze_new_tree`, `freeze_new_gen`, and the pre-existing `sort_todo_block` awk pipeline. Caught by the first `cargo test` run against the re-frozen goldens (tree-manifest mismatch, order-only, all paths present on both sides).

Both were fixed via the harness/capture-script side, not by changing `new.rs`'s actual behavior — `new.rs`'s own list-sorting for the TODO block already used plain Rust `Vec::sort()` (byte-order), so the fix was to make the ORACLE side match that convention rather than the reverse.

## Rust `new.rs` deviations from Bash (documented, all intentional)

- **TODO-list sort order** (anchor #9, see above) — Rust sorts directly; matches the canonical (already-sorted) golden, diverges from Bash's raw (unsorted) runtime stdout. Not a parity bug: the frozen oracle IS the sorted form.
- **`scripts/`/`phieu`/`templates` copy dereferences symlinks** even though Bash's `cp -R` (no `-L`) for these 3 dirs would preserve a stray symlink as a symlink rather than copying its target's content. No symlinks exist under these 3 dirs in the real kit today (only `.claude/agents`/`.claude/commands`/skills have per-file symlinks, which correctly use `-L`/deref in both Bash and Rust) — so this is a latent, currently-inert divergence, not an observed behavior difference. Flagged here for completeness in case a future kit change adds a symlink under `scripts/`/`phieu`/`templates`.
- **`.sos-stack.toml` detection logic ported in full** (all 5 stacks: node/python/requirements.txt/rust/go), even though the fixture only ever exercises the `python` branch — matches Bash's `sos_init_security` shape 1:1 rather than special-casing just the tested branch.
